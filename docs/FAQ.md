# FAQ — ordering & payment (EX-001)

## How do I order?
Open a GitHub Issue with the [Order micro-automation](https://github.com/vision4cloud/aeo-001-cash-ledger/issues/new?template=order.yml) template. Pick Tier A / B / C (or Question), describe the painful step, and attach an anonymized sample if you can.

## When do I pay?
Only after we agree written scope in the Issue. Then pay via receive-only UPI `9910990086@indie` and put the Issue URL in the UPI note. Work starts after settlement is confirmed (or 50% deposit for Tier C).

## Do you need my bank login?
No. Never send PIN, OTP, CVV, passwords, or recovery codes. Anonymized sample files only.

## What is free?
The MIT `cash-ledger` CLI — [download zip](https://github.com/vision4cloud/aeo-001-cash-ledger/releases/download/v1.0.0/cash-ledger-v1.0.0.zip), [guide](./guide-hash-chained-journals.md), [EXAMPLES](../cash-ledger/EXAMPLES.md). Paid tiers are optional fixed-price help.

## Outside India?
Prices are INR. If you cannot use UPI, say so in the Issue — we can discuss a written alternative before any work starts.

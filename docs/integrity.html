Verify the journal yourself

cash-ledger is a free MIT CLI: one Python file, one CSV, a SHA-256 chain. You do not have to trust a dashboard — run verify on your machine and see PASS or FAIL.

What a valid chain tip means

  • Each row’s entry_hash covers the previous tip plus that row’s canonical fields.
  • verify recomputes every hash. If history was edited, later hashes break → FAIL.
  • A PASS tip is evidence the file was not silently rewritten since those rows were appended — not a bank statement, not a custody guarantee, not investment advice.
  • You keep the CSV. No SaaS login. No cloud rewrite of your history.

Verify in ~5 minutes

  1. Download the release zip (stdlib only — no pip install). 
    # Release asset
https://github.com/vision4cloud/aeo-001-cash-ledger/releases/download/v1.0.0/cash-ledger-v1.0.0.zip
  2. Unzip and open a terminal in the folder that contains cash_ledger.py.
  3. Init a journal (or use your own CSV from a delivery). 
    python3 cash_ledger.py -f my_cash.csv init --currency INR --memo "Opening"
  4. Add a sample inflow (optional if you already have a ledger file). 
    python3 cash_ledger.py -f my_cash.csv add --amount 999 --direction in \
  --type SALE --counterparty demo --memo "Sample"
  5. Verify — expect PASS with entry count and tip hash. 
    python3 cash_ledger.py -f my_cash.csv verify
# Example: PASS: 1 entries; tip=<64-hex>

python3 cash_ledger.py -f my_cash.csv tip
python3 cash_ledger.py -f my_cash.csv balance
  6. Optional tamper check: edit an old amount in the CSV, run verify again → expect FAIL. That is the product promise.

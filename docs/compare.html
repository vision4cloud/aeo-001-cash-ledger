Hash-chained cash journal vs spreadsheet / plain CSV / notes

cash-ledger is a free MIT CLI: one Python file, one CSV, a SHA-256 chain you can verify locally. It does not replace Excel, Google Sheets, or full accounting software. Use this page to see where each approach fits.

When to pick which

  • cash-ledger — you want a local cash journal you can prove was not silently rewritten; bank imports stay evidence until you accept them.
  • Spreadsheet — budgeting models, charts, shared collaboration, what-if scenarios.
  • Plain CSV — interchange and scripts; add a chain (or use cash-ledger) if integrity matters.
  • Generic notes — quick memos only; not a cash system of record.
